# Build an AI Machine

A practical, community-maintained guide to building a local AI workstation, starting with one or two RTX 3090 GPUs and UK used-market platform prices.

- **[Read the editable Markdown guide](dual_3090_uk_platform_guide.md)**
- **[View the illustrated HTML guide](https://turbo-tan.github.io/buildAIMachine/dual_3090_uk_platform_guide.html)**
- [Download the standalone HTML](https://github.com/turbo-tan/buildAIMachine/raw/refs/heads/main/dual_3090_uk_platform_guide.html)

## Corrections and suggestions welcome

[Open an issue](https://github.com/turbo-tan/buildAIMachine/issues/new/choose) to suggest a better-value platform, correct a specification, share a completed build, or contribute measurements. Pull requests are welcome too.

Useful evidence includes the exact motherboard model and revision, CPU, RAM configuration, GPU slot wiring and spacing, dated listing links, and reproducible benchmarks. Distinguish asking prices from completed sales and measured performance from estimates.

The Markdown file is the editable text companion to the illustrated HTML. If you change prices or technical claims, update both versions and their dates, or explain any remaining HTML update in your issue or pull request.

## Scope

The initial guide is a **21 November 2026 UK price snapshot**. Its totals exclude GPUs, case, storage, cooler and shipping. Prices change; compatibility depends on the exact components. Two 24 GB cards do not automatically provide a single 48 GB memory pool, and NVLink support depends on both hardware and software.
